# pureinit

A tool for cleaning redundant code from templates, currently used to clean Zig project templates generated by `zig init`.

> [!WARNING]
> Note: This project is intended only for code that has not been modified since initialization. Do not use it on modified projects.

## Introduction

This tool extracts cleanup information from patches generated by git-diff. It does not scan for code targets or comments. Therefore, it is effectively generic and can perform cleanup from external patches. The built-in patches are actually located in the [src/diff_patchs](src/diff_patchs) source directory.

## Usage

For the `zig init` template in Zig 0.17.1, it has:

```plaintext
-------------------------------------------------------------------------------
Language                     files          blank        comment           code
-------------------------------------------------------------------------------
Zig                              4             29            115            101
-------------------------------------------------------------------------------
SUM:                             4             29            115            101
-------------------------------------------------------------------------------
```

It is filled with a large number of comments (115 lines) and example code (more than half). This may help beginners, but it is meaningless for experienced users. In my view, this is all "noise."

Use `pureinit` to clean it (it detects the version in `build.zig.zon` and uses the corresponding patch):

```sh
$ pureinit
Patch info:
+-----------------------+----------+-----+--------+
| name                  | from     | env | ver    |
+=======================+==========+=====+========+
| zig-init.0.17.1.patch | builting | zig | 0.17.1 |
+-----------------------+----------+-----+--------+
Apply patch to: '.'? [y/N]: y
INFO Applying build.zig
INFO Applying build.zig.zon
INFO Applying src/main.zig
INFO Applying src/root.zig
```

Afterward:

```plaintext
-------------------------------------------------------------------------------
Language                     files          blank        comment           code
-------------------------------------------------------------------------------
Zig                              4              9              2             43
-------------------------------------------------------------------------------
SUM:                             4              9              2             43
-------------------------------------------------------------------------------
```

The project template is now very clean! You can view these cleaned templates in the [templates](templates) directory.

## Building

This is a pure Zig project, so:

```sh
zig build
```

Install it to the system (the user bin directory):

```sh
zig build --release=safe install --prefix ~/.local
```

## For Other Projects

Because it is generic by design, you can create your own patches and use `pureinit` to clean them. First (assuming your framework is called `foo`):

```sh
foo init
```

- Commit the original template code to Git, then perform the manual cleanup.
- When finished, add the modifications to the staging area.

Now you can generate a patch:

```sh
git diff --cached HEAD | save foo-init.0.0.1.patch
```

Use `pureinit` to apply your custom patch:

```sh
pureinit -p foo-init.0.0.1.patch
```

_Note: `pureinit` does not delete files, because cleaning `zig init` does not currently require this._
