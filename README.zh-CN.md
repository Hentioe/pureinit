# pureinit

一个用于清理模板中多余代码的工具，目前用于清理 `zig init` 生成的 Zig 项目模板。

> [!WARNING]
> 注意：此项目仅用于「初始化后未改动」的代码，请不要用于已修改的项目。

## 介绍

此工具从 git-diff 生成的补丁提取清理信息，不扫描任何代码“靶点”、注释。因此，它实际上是通用的，可以从外部补丁来执行清理。实际上，内建补丁就在 [src/diff_patchs](src/diff_patchs) 源码目录下。

## 使用

对于 Zig 0.17.1 的 `zig init` 模板，它有：

```plaintext
-------------------------------------------------------------------------------
Language                     files          blank        comment           code
-------------------------------------------------------------------------------
Zig                              4             29            115            101
-------------------------------------------------------------------------------
SUM:                             4             29            115            101
-------------------------------------------------------------------------------
```

充斥着大量的注释（115 行）、示例代码（一半以上）。这对于初学者可能有帮助，但对于“老鸟”毫无意义。在我看来，这些都是“噪音”。

使用 `pureinit` 清理（它会识别 `build.zig.zon` 中的版本，并使用对应补丁）：

```sh
$ pureinit
Patch info:
+-----------------------+----------+-----+--------+
| name                  | from     | env | ver    |
+=======================+==========+=====+========+
| zig-init.0.17.1.patch | builting | zig | 0.17.1 |
+-----------------------+----------+-----+--------+
Apply patch to: '.'? [y/N]: y
INFO Applying build.zig
INFO Applying build.zig.zon
INFO Applying src/main.zig
INFO Applying src/root.zig
```

之后：

```plaintext
-------------------------------------------------------------------------------
Language                     files          blank        comment           code
-------------------------------------------------------------------------------
Zig                              4              9              2             43
-------------------------------------------------------------------------------
SUM:                             4              9              2             43
-------------------------------------------------------------------------------
```

现在项目模板已经变得非常干净！你可以从 [templates](templates) 目录查看这些清理后的模板。

## 构建

它是一个纯 Zig 项目，因此：

```sh
zig build
```

安装到系统（用户 bin 目录）：

```sh
zig build --release=safe install --prefix ~/.local
```

## 用于其它项目

由于它在设计上是通用的，因此你可以自制补丁，并用 `pureinit` 来执行清理。首先（假设你的框架叫 `foo`）：

```sh
foo init
```

- 将原生的模板代码提交到 Git，然后再执行“手动”清理。
- 完成后，将修改添加到暂存区。

现在，你可以生成补丁了：

```sh
git diff --cached HEAD | save foo-init.0.0.1.patch
```

用 `pureinit` 来应用你自制的补丁：

```sh
pureinit -p foo-init.0.0.1.patch
```

_注意：`pureinit` 不执行文件删除，因为目前清理 `zig init` 没有这个需要。_
